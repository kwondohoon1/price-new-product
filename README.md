# 가격세팅 신제품 추가

가격세팅 엑셀(`YYMMDD_가격세팅.xlsx`)에 신제품을 넣어 주는 정적 페이지입니다.
상품명과 원가만 넣으면 네 시트의 같은 자리에 행을 끼우고, 수식·서식은 윗행에서 이어받습니다.

**페이지:** https://kwondohoon1.github.io/price-new-product/

## 쓰는 법

1. 가격세팅 파일을 끌어 놓습니다.
2. 상품명·원가를 넣습니다. 브랜드·카테고리는 상품명으로 추정해 채우고, 넣을 자리는 같은 카테고리·브랜드의 마지막 상품 다음이 기본입니다.
3. 노출가는 선택입니다. 넣으면 G마켓·자사몰 기준 정산가·마진율과 마켓별 등재가를 바로 보여 줍니다. 비우면 입력가(E열)를 빈칸으로 두며, 엑셀에서 입력가만 넣으면 나머지가 계산됩니다.
4. **신제품 넣은 엑셀 만들기 → 내려받기.** 파일명 앞 6자리는 오늘 날짜로 바뀝니다.

## 시트별로 하는 일

네 시트의 상품 표는 같은 순서로 맞물려 있습니다(마켓별상품코드 n번째 = 정산가세팅 각 표의 n번째 = 최저가비교 n번째 = G마켓_프로모션 n번째). 그래서 자리 하나를 정하면 모든 표의 같은 위치에 넣습니다.

| 시트 | 넣는 내용 |
|---|---|
| 마켓별상품코드 | 카테고리·브랜드·모델명·마켓 코드. 등재가(%)와 수식은 윗행에서 |
| 정산가세팅(표마다) | 기준·수식은 윗행에서, 입력가 = 노출가(비우면 빈칸), 원가. 자사몰 기준 표의 원가는 위 표를 가리키는 수식 |
| 최저가비교 | 현재세팅 값, 제안 = 현재, 판정 "비교 불가". 다나와코드는 동일스펙 사이트에서 다시 받으면 채워짐 |
| G마켓_프로모션 | 행 자리만 맞춤. 행사 신청 대상이 아니므로 상품명·노출가만 적고 행사 수식은 넣지 않음 |

- 행을 끼울 때 모든 시트의 수식 참조, 병합, 유효성 검사, 조건부 서식, 하이퍼링크, 필터, 메모 위치를 Excel과 같은 규칙으로 옮깁니다.
- 표 끝에 붙여 넣으면 Excel은 범위를 늘리지 않으므로, 본보기 행을 덮던 유효성 검사·조건부 서식·필터 범위는 새 행까지 늘립니다.
- 모든 수식을 다시 계산해 값을 저장하고, Excel이 열 때도 전체를 다시 계산하게 합니다.
- 최저가비교·G마켓_프로모션의 순서가 마켓별상품코드와 다르면 그 시트는 건드리지 않고 알려 줍니다.

## 개인정보

- 파일은 브라우저 안에서만 처리합니다. CSP로 외부 연결(`connect-src 'none'`)을 막았습니다.
- 레포에는 엑셀·CSV를 올리지 않습니다. `.gitignore`는 허용 목록 방식이고, `.githooks/pre-commit`이 데이터 파일과 워크북 XML을 막습니다.

## 개발

```bash
npm install
npm test
```

```bash
PNP_FIXTURE="레포 밖/261012_가격세팅.xlsx" npm test
```

```bash
node tools/add.mjs 입력.xlsx 레포밖/결과.xlsx 상품.json
```

- `src/book.js`: xlsx XML 열기·저장, 행 끼우기와 참조 옮기기, 수식 재계산
- `src/newproduct.js`: 표 찾기, 넣을 자리, 시트별 행 채우기
- `src/formula.js`: 작은 엑셀 수식 계산기(매출현황 최신화 도구에서 가져옴)
- 검증: Excel이 직접 같은 자리에 행을 끼운 파일과 수식·병합·유효성 검사·조건부 서식·하이퍼링크·필터를 대조했고, Excel 재계산 값과 저장 값이 전부 같았습니다.
